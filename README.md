# W2S-Eval: Weak-to-Strong Alignment Protocol

A research-grade implementation of confidence-gated weak-to-strong supervision for frontier AI alignment.

## Features
- **Confidence-Gated KL Loss**: Prevents strong student models from imitating hallucinations of weaker supervisors.
- **Modular Pipeline**: Clean separation of supervisor models, student architectures, and training loops.
- **Zero Heavy External Dependencies**: Runs on standard PyTorch.
